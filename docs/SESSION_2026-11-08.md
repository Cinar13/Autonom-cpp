For reference, earlier sessions at 0.6 m/s: typical laps 15.5–17.5 s. The first lap of each row is the switch from
the 0.3 m/s mapping speed. Gazebo caps the TurtleBot3's acceleration at ~1.0 m/s².

Other findings:
- Crash tests (side shoves up to 45 N with a spin, rear-end, head-on): the robot never tipped (worst 19°), SLAM recovered
  within 3–8 s (error ≤ 0.07 m). Very hard shoves near the start line caused reverse crossings (before the gate fix).
- The odometry heading drifts (up to 0.24 rad, the wheels under-read turns by ~5 % at speed); SLAM corrects it and the
  local costmap still lines up with the map (0–10 % stray cells, cleared within seconds). Not a problem so far.
- With the simulated BNO055 bias (stash) the heading drifted ~0.4 °/s while standing still; the bias compensator
  addresses that but is untested.
